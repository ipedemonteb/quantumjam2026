# Scale SQD chemistry workflows with Dice solver

> Fuente: <https://github.com/Qiskit/qiskit-addon-sqd/blob/main/docs/guides/integrate_dice_solver.ipynb>

This guide shows how to use the Dice solver as an alternative SCI solver to diagonalize larger Fermionic problems beyond what the default PySCF solver can support. For information on how to install and use ``qiskit-addon-dice-solver``, [visit the documentation](https://qiskit.github.io/qiskit-addon-dice-solver/). For more details on the SQD code used in this example, see the [chemistry Hamiltonian tutorial](https://quantum.cloud.ibm.com/docs/tutorials/sample-based-quantum-diagonalization).
