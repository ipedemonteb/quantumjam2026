# PySCF

> Fuente: <https://pyscf.org> — código en <https://github.com/pyscf/pyscf>, documentación en <https://github.com/pyscf/pyscf.github.io>.

PySCF es una librería de química cuántica en Python (Apache-2.0). En este proyecto se usa para el Hamiltoniano molecular de H₄ en STO-3G y para las referencias clásicas HF, CCSD y FCI. Las páginas de esta carpeta son la documentación de usuario convertida desde reStructuredText a MyST markdown.

Página principal: *Quantum chemistry with Python* — primariamente Python, rápido (NumPy, SciPy y código C/C++), libre y abierto, modular, completo y extensible.
