# Material para la presentación

Pensado para las 4 personas del equipo, asumiendo cero base previa de computación cuántica.

- [`guion.md`](guion.md): el guion en 6 bloques (repartibles entre las 4 personas), con analogías,
  los resultados reales y las preguntas que es probable que haga el jurado.
- [`glosario.md`](glosario.md): definiciones cortas de los términos técnicos, para tener a mano
  durante preguntas.
- [`img/curva_energia.png`](img/curva_energia.png): el gráfico de apoyo (energía vs. distancia,
  VQE/CCSD/FCI, con el punto de equilibrio real marcado). Se regenera con el script de la sesión que
  lo creó; si los números del notebook cambian, hay que volver a generarlo.

Para los números y el detalle técnico de qué se hizo y qué falta, ver [`../bitacora.md`](../bitacora.md).
